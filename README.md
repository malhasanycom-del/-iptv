# آل راشد IPTV

تطبيق أندرويد بسيط لتشغيل قوائم IPTV بصيغة M3U وM3U8.

## الميزات
- واجهة عربية.
- لصق رابط قائمة M3U/M3U8 عبر HTTP أو HTTPS.
- تحميل القنوات وعرضها.
- تشغيل القناة داخل التطبيق مع أدوات تشغيل ومؤشر تحميل.

## بناء APK
يُبنى التطبيق تلقائياً عبر GitHub Actions عند كل دفع إلى الفرع main. افتح تبويب **Actions** في المستودع، ثم افتح آخر تشغيل ناجح ونزّل الملف من **Artifacts** باسم `al-rashed-iptv-debug-apk`.

> يتطلب التطبيق رابط قائمة IPTV صالحة تملك حق استخدامها. هذا الإصدار يدعم قوائم M3U/M3U8؛ لا يتضمن تسجيل دخول Xtream Codes أو Stalker Portal حتى الآن.
