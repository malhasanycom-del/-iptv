# ال راشد IPTV — Android starter project

نسخة أولية مفتوحة المصدر لمشغّل قنوات مباشرة فقط، مهيأة لتجربة Android phones وAndroid TV / Google TV.

## الوظائف الموجودة في هذه البداية
- واجهة عربية داكنة متكيّفة.
- حقول اتصال Stalker Portal + MAC، Xtream Codes، وM3U/M3U8.
- قراءة قوائم M3U، ومحاولة جلب القنوات المباشرة من Xtream.
- تجربة أولية لبروتوكول Stalker/MAG (handshake ثم get_all_channels).
- تشغيل الفيديو عبر AndroidX Media3/ExoPlayer.
- بحث ومفضلة داخل الجلسة.

## متطلبات البناء
- Android Studio حديث يدعم Android Gradle Plugin 8.7.3 وJDK 17.
- افتح مجلد المشروع `alrashed_iptv` في Android Studio ثم دع Gradle يزامن الاعتماديات.
- شغّل التطبيق على جهاز أندرويد أو محاكي مناسب.

## حدود النسخة الأولية
- هذه ملفات مصدر أولية وليست APK مبنياً أو مختبراً على أجهزة فعلية.
- Stalker يختلف بين مزوّد وآخر؛ بعض البوابات تحتاج headers أو API أو مصادقة إضافية. تدفق create_link في هذه البداية ليس محللاً كاملاً لكل صيغ أوامر Stalker، لذلك يلزم اختباره وتعديله مع بوابة مصرّح لك باستخدامها.
- Xtream category grouping وEPG وملفات M3U المحلية وXMLTV وpersisted favorites ليست مكتملة بعد.
- لا توجد مزامنة سحابية بين الهاتف والتلفزيون في هذه النسخة.
- أمان بيانات الاشتراك يحتاج تحسيناً قبل النشر العام؛ لا تستخدم بيانات حساسة حقيقية في نسخة التطوير غير المختبرة.
- لا يمكن ضمان إزالة التقطيع إذا كان مصدر البث أو اتصال الإنترنت غير مستقر.

## الخطوات التالية المقترحة
1. بناء المشروع والتحقق من توافق المكتبات على Android Studio.
2. اختبار M3U وXtream على روابط اختبار قانونية.
3. اختبار Stalker على بوابة مصرح بها وتحسين handshake / create_link / headers بحسب ردود الخادم.
4. إضافة تخزين آمن للمعلومات، EPG، إعدادات Buffer قابلة للضبط، وإدارة focus للريموت.
